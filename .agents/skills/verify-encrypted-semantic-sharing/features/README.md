# Verification map

The driver is implemented but remains a draft until native Ubuntu CI proves it. Install the research requirements and editable package, download the pinned model, then run `launch`, `doctor`, `drive`, and `cleanup` with the same `run_id`. Each mapped journey is exercised by `drive` against the real app and two sidecars.

- [Authorize, import, and revoke a share](./share-authorization.md)
- [Search the current session](./semantic-search.md)
